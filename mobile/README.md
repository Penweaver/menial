# Menial Mobile App

> React Native / Expo / TypeScript mobile application for Employers and Workers.

This directory will contain the Expo mobile app. Scaffolding will be created in a later phase.

## Planned Structure

```
/mobile
├── app/              # Expo Router file-based routing
├── components/       # Reusable UI components
├── services/         # Service abstractions (auth, payment, sms, etc.)
├── hooks/            # Custom React hooks
├── constants/        # Theme tokens, config
├── utils/            # Helper utilities
└── assets/           # Images, fonts
```
